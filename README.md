# «Кто я в блоге?» — код креатора

Telegram Mini App, которое собирает четыре системы в один ответ: **что снимать, как снимать и каким быть в кадре**.

| Система | Что считается | Что даёт креатору |
|---|---|---|
| Натальная карта | 10 планет, истинный узел, асцендент, MC, дома Плацидуса, ретроградность, баланс стихий; разбор каждой точки | стиль проявления, эстетика, что заряжает и тормозит |
| Архетипы | 72 утверждения по конструкциям Heroic Myth Index (К. Пирсон): 12 архетипов × 6, баллы 6–30, зоны 6–11 / 12–17 / 18–23 / 24–30; уточняющий раунд только при равных максимальных баллах; результат — контент-паспорт автора | каким быть в кадре, свет/камера/палитра, кино-референсы, темы, хуки |
| Нумерология | путь, выражение, душа, личность, день рождения, зрелость, квадрат Пифагора (ячейки и 8 линий), вершины и вызовы, кармические уроки, личный год/месяц/день | роль, тон голоса, темы, «энергия дня» |
| Дизайн человека | 26 активаций, 64 ворот, 36 каналов, 9 центров → тип, авторитет, профиль, бодиграф | ритм публикаций, как принимать решения о контенте |

Сверху — **Код креатора**: формула (например «Мудрец + Рыбы · Вода + Путь 1 + Манифестор 2/5»), три правила-«таблетка», блоки «Каким быть / Как снимать / Что снимать / Ритм / Ловушка» с метками, из какой системы пришёл каждый совет, и энергия дня.
**Спросить** — чат: отвечает на вопросы, опираясь на весь профиль. **Контент** — рейтинг форматов по голосам всех систем, генератор идей, раскадровка, план на 7 дней.

## Запуск в Telegram (без ИИ — работает сразу)

1. GitHub → New repository → Public → **Add file → Upload files** → перетащи содержимое папки → Commit.
2. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save. Адрес: `https://ЛОГИН.github.io/РЕПО/`.
3. @BotFather → `/newbot` → потом `/mybots` → бот → **Bot Settings → Menu Button** → вставь адрес.
   Для ссылки вида `t.me/бот/app`: `/newapp` → тот же адрес.
4. В `js/config.js` впиши `botUrl`, `contactUrl`, `channelUrl`.

Без ИИ раздел «Спросить» отвечает встроенными ответами из базы — они собираются из твоего кода и тоже персональные.

## Подключение ИИ (≈15 минут)

Ключ API нельзя класть в код на GitHub — его украдут. Поэтому между приложением и ИИ стоит маленькая прослойка.

1. Зарегистрируйся на **dash.cloudflare.com** (бесплатно) → **Workers & Pages → Create → Worker** → Deploy.
2. **Edit code** → удали всё → вставь содержимое `worker/worker.js` → Deploy.
3. **Settings → Variables and Secrets** → добавь:
   - `API_URL` — адрес OpenAI-совместимого API (OpenAI, OpenRouter, ProxyAPI и т. п. — см. комментарий в файле);
   - `API_KEY` — ключ (тип Secret);
   - `MODEL` — модель, например `gpt-4o-mini`;
   - `BOT_TOKEN` — токен бота (Secret): прослойка будет пускать только пользователей из Telegram;
   - `ALLOWED_ORIGIN` — `https://ЛОГИН.github.io`.
4. Скопируй адрес воркера (`https://….workers.dev`) в `js/config.js` → `aiEndpoint`.

Что уходит в ИИ: рассчитанный профиль (знаки, архетипы, числа, тип ДЧ, ниша) и вопрос. Дата, время и место рождения не отправляются.
Стоимость: ответ ~500–800 токенов; у недорогих моделей это доли рубля за ответ. Прослойка ограничивает длину ответа (`max_tokens: 600`). Лимит запросов на пользователя пока не стоит — добавь, когда будет трафик.

## Оценки точности теста архетипов
После результата человек отвечает «Насколько точно это про тебя?» (1–5). Если ставит 3 или ниже — выбирает, какой архетип считает своим ведущим.
Чтобы ответы приходили тебе в Telegram:
1. Узнай свой Telegram ID у @userinfobot.
2. В воркере (см. «Подключение ИИ») добавь переменные `BOT_TOKEN` и `ADMIN_CHAT_ID` (твой ID). Перед этим один раз напиши своему боту /start — иначе он не сможет тебе писать.
3. В `js/config.js` впиши `feedbackEndpoint: 'https://….workers.dev/feedback'`.
Каждый ответ придёт сообщением: оценка, что показал тест, что считает человек, баллы по 12 архетипам, его ник. Подделать запрос в обход Telegram нельзя — воркер проверяет подпись.

## Точность расчётов
- Планеты — Astronomy Engine. Сверено со Swiss Ephemeris (её используют астрологические программы) на 300 случайных датах 1930–2025: планеты < 0,5′, истинный узел < 1′, асцендент, MC и куспиды Плацидуса < 0,1′ (тест tests/natal.test.mjs с эталонными значениями).
- Зодиак тропический, дома — Плацидус (за полярным кругом — Порфирий). Часовые пояса — с историческими изменениями.
- Дизайн человека: ворота 41 начинаются с 2° Водолея, момент дизайна — Солнце на 88° раньше, узлы истинные. Проверено тестами: распределение типов на 1500 случайных дат — генераторы 34%, МГ 30%, проекторы 24%, манифесторы 10%, рефлекторы 1%. Без времени рождения ДЧ не считается.
- Нумерология: пифагорейская таблица, кириллица (А=1 … Я=6) и латиница, мастер-числа 11/22/33.

## Ограничения
- Данные хранятся в `localStorage` на устройстве; на другом телефоне код собирается заново.
- Оплата не подключена: тарифы показываются, «Хочу» ведёт на `contactUrl` (проверка спроса).
- Это инструмент саморефлексии и вдохновения, не диагностика: в текстах мягкие формулировки, ИИ запрещено предсказывать судьбу и давать медицинские/финансовые советы.

## Мастерская
- **Движок хуков (СТОП)** — по ТЗ автора. От ниши: карта аудитории (5 болей, 4 желания, 3 страха, 3 мифа, 3 возражения) и 20 хуков. От сценария: разбор (тема, инсайт, цифры, повороты, эмоция, зритель) и 20 хуков, которые ведут именно в этот сценарий и используют его цифры. У каждого хука — формула, триггер, оценка С/Т/О/П и «почему работает»; хуки ниже 25 не выдаются; в конце — топ-3. Команды: «Ещё 20» (без повторов), «Докрути» (агрессивнее / загадочнее / конкретнее), ♥ «Нравится» (смещает следующие партии), «Только 30+», «Голосом/Текстом». Если подключён ИИ, движок работает по полному ТЗ из js/stop-spec.js; без ИИ — на шаблонах с той же логикой.
- **Идеи** — хук из базы ниши + структура под формат; «Сгенерировать заново» всегда даёт новые идеи.
- **План на месяц** — 4 недели = доверие → польза → вовлечение → продажа, 3/5/7 публикаций в неделю, хук и призыв к действию на каждый день.
- **Шапка профиля** — поле «Имя» для поиска и 5 вариантов описания до 150 знаков (классика, через результат, три стиля твоих архетипов).
- **Чек-лист съёмки** — 42 пункта от подготовки до бэкапа + пункты под твой архетип, цветотип, канал восприятия и хронотип.
Ниши без совпадения в базе работают через универсальные формулировки «в теме «…»». Чтобы добавить нишу — допиши блок в `js/niches.js` по образцу.

## Снимать без страха и разбор роликов
- **Страхи** — тест на 10 утверждений, порядок проработки, разбор каждого страха: откуда, как на самом деле, что делать, упражнение на сейчас, ход под архетип, ролик из страха.
- **Тренажёр «Не боюсь камеры»** — 21 день с растущей сложностью, запись дублей (хранятся только на телефоне), график уровня страха, сравнение «до/после» (дни 5 и 21).
- **Разминка речи** — дыхание, артикуляционная гимнастика, голос, упражнение с пробкой, скороговорки по звукам; разминка 5 минут с таймером.
- **Почему не залетело** — анкета из 12 вопросов + цифры статистики + анализ видео прямо в браузере: формат, разрешение, яркость, смена кадра, статичное начало, тишина в начале, громкость, паузы, перегруз. Итог — оценка, главная причина, правки и новые хуки.
- **Карточка «Мой код»** — анимированная карточка в приложении, PNG 1080×1920 и моушн-видео на 6 секунд для сторис.
- **Актуальные-воронки** — 4 актуальных по болям ниши, сценарий на 5/7/10/12 сторис (что сказать, что показать, какой стикер), лид-магнит и кодовое слово.

### ИИ-разбор роликов за звёзды Telegram
1. В воркере создай KV (Settings → Bindings → KV namespace) с именем `DB`.
2. Переменные: `VISION_MODEL` (модель, понимающая картинки, например `gpt-4o-mini`), `FREE_ANALYSES` (бесплатных разборов, по умолчанию 1), `STARS_P5` (цена 5 разборов в звёздах, по умолчанию 150), `WEBHOOK_SECRET` (любая строка), `APP_URL`.
3. Привяжи вебхук бота к воркеру (один раз, в браузере):
   `https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://….workers.dev/tg&secret_token=<WEBHOOK_SECRET>`
   Если у бота уже есть свой вебхук — используй для оплат отдельного бота.
4. В `js/config.js`: `analyzeEndpoint: 'https://….workers.dev/analyze'`.
В ИИ уходят только 6 кадров по 360 px и технические цифры, само видео не загружается.

### Напоминания тренажёра
Нужны KV `DB` и Cron-триггер `0 * * * *` (Settings → Triggers). В `js/config.js`: `remindEndpoint: 'https://….workers.dev/remind'`. Бот присылает задание дня в выбранный час по местному времени человека.
